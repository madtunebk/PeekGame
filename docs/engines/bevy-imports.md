# Bevy Engine Import Ledger & Progress Tracker

## Engine Baseline

- **Engine:** [Bevy Engine](https://bevyengine.org/) (Version `0.12.1`)
- **Compilation Target:** Rust `x86_64-pc-windows-msvc` (Visual Studio 2019/2022 toolchain)
- **Primary Game Binaries:**
  - `arbgeom.exe` (4D geometric puzzle game)
  - `marching_ants_game.exe`
- **Underlying Runtimes & Crates:**
  - **Windowing & Input:** `bevy_winit 0.12.1`, `winit 0.29` (Win32 raw input, touch events, DPI, display settings)
  - **Graphics & Presentation:** `bevy_render 0.12.1`, `wgpu 0.18`, `wgpu-hal` (Vulkan/DX12 translation, DXVK, DWM blur, icon management)
  - **Asynchronous I/O:** `async-io 2.x`, `polling 3.x`, `windows-sys 0.52` (NT I/O completion, `NtReadFile`, `NtWriteFile`, `SetFileInformationByHandle`)
  - **System & Security:** `sysinfo`, `windows-sys` (SID querying, token security, LSA session enumeration, process counters, memory querying)
  - **C/C++ Runtime:** MSVC UCRT (`api-ms-win-crt-runtime-l1-1-0.dll`) and `VCRUNTIME140.dll` (SEH filters, C++ exception ABI, TLS atexit handlers)
- **Link-Time Status:**
  - Link-time bound slots: **296**
  - Program DLLs bound at startup: **11**
  - Unresolved imports: **0** (All required imports resolved and bound)

## Architecture & Conventions

All imports adhere strictly to PeekGame's modular separation:
1. **Implementation (`src/api/<subsystem>/`):** Pure Win64 calling convention implementations with Linux host backend mappings, POSIX error translation, and explicit unsafe blocks.
2. **Registry (`src/registry/<subsystem>.rs`):** Export symbol tables, link aliases (`peekgame.<dll>.<func>`), and canonical DLL routing via `src/registry/mod.rs`.

## Detailed Import Ledger (48 Resolved Imports)

### 1. Universal C Runtime (`api-ms-win-crt-runtime-l1-1-0.dll` / `msvcrt.dll`)

#### `api-ms-win-crt-runtime-l1-1-0.dll!_c_exit`
- **Trigger:** Engine quick exit / process abort paths.
- **Contract:** `void __cdecl _c_exit(void)`.
- **Implementation:** `src/api/crt/startup.rs::c_exit`, registered in `src/registry/crt.rs`.
- **Critical Invariant:** Must **not** run termination callbacks (`run_callbacks()`). Unlike `_cexit`, `_c_exit` performs quick cleanup without executing `atexit` or `_onexit` handlers, preventing premature or double-cleanup corruption.
- **Scope:** Clean return without invoking callbacks.

#### `api-ms-win-crt-runtime-l1-1-0.dll!_register_thread_local_exe_atexit_callback`
- **Trigger:** Rust standard library / MSVC startup initializing dynamic thread-local storage (TLS) destructors.
- **Contract:** `int __cdecl _register_thread_local_exe_atexit_callback(_tls_callback_type callback)`.
  - Signature: `extern "win64" fn(*mut c_void, u32, *mut c_void)` (`image_base`, `reason`, `reserved`).
- **Implementation:** `src/api/crt/startup.rs::register_thread_local_exe_atexit_callback`, registered in `src/registry/crt.rs`.
- **Critical Invariant:**
  - Distinct from standard parameterless `atexit` callbacks.
  - Callbacks stored in dedicated `TLS_CALLBACKS` registry.
  - Executed in strict **LIFO** (reverse registration) order.
  - Dispatched on thread termination (`reason = 3`: `DLL_THREAD_DETACH`) in `src/host/thread_template.rs::detach()`.
  - Dispatched on process termination (`reason = 0`: `DLL_PROCESS_DETACH`) in `cexit()` before ordinary atexit callbacks.

#### `api-ms-win-crt-runtime-l1-1-0.dll!_seh_filter_exe`
- **Trigger:** MSVC CRT executable startup exception handling wrapper.
- **Contract:** `int __cdecl _seh_filter_exe(unsigned long xcptnum, struct _EXCEPTION_POINTERS *pxcptinfoptrs)`.
- **Implementation:** `src/api/crt/startup.rs::seh_filter_exe`, registered in `src/registry/crt.rs`.
- **Scope:** Returns `0` (`EXCEPTION_CONTINUE_SEARCH`).

#### `api-ms-win-crt-runtime-l1-1-0.dll!terminate`
- **Trigger:** Rust panic runtime or unhandled C++ exception fatal teardown.
- **Contract:** `void __cdecl terminate(void)`.
- **Implementation:** `src/api/crt/ucrt.rs::terminate`, registered in `src/registry/crt.rs`.

  3. **Vulkan Debug Utils ABI Trampoline:**
     - **Issue:** WGPU attaches `VkDebugUtilsMessengerCreateInfoEXT` to `VkInstanceCreateInfo.pNext`. When passed to host `libvulkan.so.1`, Linux driver called `pfnUserCallback` with System V ABI, corrupting registers and causing `0xc0000005` in Windows x64 code.
     - **Fix:** Added `vk_debug_trampoline` translating System V ABI to Win64 ABI, and wrapped `pNext` in `src/api/graphics/vulkan.rs::create_instance` and `create_debug_utils_messenger`.
  4. **Window Owner Thread Enforcement:**
     - **Issue:** WGPU background worker threads probed OpenGL, creating dummy contexts and panicking in `glow`.

  5. **Winit Redraw & Event Pumping (`RDW_INTERNALPAINT`):**
